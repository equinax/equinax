# 龙头涨停 (Dragon Leader) 理论纲领

## 1. 核心理念

发掘中线即将起爆涨停的潜力票。以 T+20 收益率和胜率为核心评估指标。

涨停不是随机事件——它是资金、情绪、结构三者共振的产物。本策略的核心是从**行为学**角度出发，通过量价数据反推背后的操盘意图和资金行为，在涨停发生前 T-5 至 T-20 的窗口中捕捉蓄力信号。

---

## 2. 涨停行为微观结构

### 2.1 生命周期模型

每一次涨停事件都遵循一个可识别的行为生命周期。不同阶段具有不同的量价特征：

```
吸筹 → 拉升 → 回踩 → 确认 → 主升 → 分歧 → 退潮
```

| 阶段 | 行为特征 | 量价表现 | 可观测信号 |
|------|----------|----------|------------|
| **吸筹** | 主力低位建仓，压制股价在窄幅震荡 | 缩量横盘，换手率低但稳定递增 | `accumulation_score`↑, `vol_cv_10d`↓, `turnover_change_20d` 缓升 |
| **拉升** | 试探性拉升，测试抛压和跟风意愿 | 放量上涨，上影线较长 | `vol_ramp_5v20`↑, `upper_shadow_ratio`↑, `main_strength_proxy`↑ |
| **回踩** | 洗盘，清洗浮筹，测试支撑位 | 缩量回落，但不破关键均线 | `post_spike_consolidation`↓, `price_range_position_20d` 回中 |
| **确认** | 回踩后企稳，量能再次温和放大 | 低位缩量止跌 + 反弹放量 | `ma_alignment_score`↑, `stability_score`↓, `volume_buildup_quality`↑ |
| **主升** | 涨停爆发，连板或大阳线 | 巨量封板，换手率飙升 | 涨停触发（事件本身） |
| **分歧** | 多空博弈加剧，市场对后续走势存疑 | 高位放量震荡，涨停后次日大幅高开低走 | `climax_score`↑, `exhaustion_at_ceiling`↑ |
| **退潮** | 资金撤退，获利盘出逃 | 放量下跌或连续阴线 | `recent_vol_spike_max`↑ + 价格下行 |

**我们的目标窗口**：在 **吸筹→确认** 阶段介入，在 **主升** 阶段获利。避开 **分歧→退潮** 阶段。

### 2.2 操盘角色分类

涨停背后存在不同类型的操盘主体，其行为特征、持续期和量价签名有显著差异：

#### 游资短线操盘（持续 1-3 日）

- **行为模式**: 快速建仓→猛烈拉升→次日出货。通常选择小市值、题材热点股。
- **量价特征**:
  - 突然放巨量（`vol_ramp_5v20` > 0.5），之前无明显吸筹期
  - 换手率骤升（`turn_ramp_5v20` 极端值）
  - 封板时间晚（尾盘封板）或反复开板
  - 上龙虎榜频繁
- **可利用性**: 低。爆发性强但持续期短，T+20 评估期内大概率已回落。
- **识别要点**: `vol_ramp_5v20` 极端 + `accumulation_score` 低 + `turnover_change_20d` 无前期爬升

#### 机构主导运作（持续 1-4 周）

- **行为模式**: 缓慢吸筹→逐步拉升→阶梯式上涨→分批出货。偏好基本面支撑的标的。
- **量价特征**:
  - 吸筹期成交量温和放大（`accumulation_score` 持续走高）
  - 拉升期量价齐升，但上影线短（`upper_shadow_ratio` 低）
  - 主力资金净流入持续正值（`main_strength_proxy`↑, `mf_net_percentile`↑）
  - 价格沿 MA5/MA10 稳步推进（`ma_alignment_score` 高）
- **可利用性**: 高。持续期匹配 T+20 评估窗口，胜率和收益均较优。
- **识别要点**: `accumulation_score`↑ + `main_strength_proxy`↑ + `ma_alignment_score`↑ + `vol_cv_10d` 适中

#### 板块轮动共振（持续 1-2 周板块级别）

- **行为模式**: 政策/事件驱动，板块内个股依次启动，龙头先涨停带动跟风。
- **量价特征**:
  - 板块指数先行走强（`sector_momentum_5d`↑）
  - 同板块多只股票同日涨停或近日连续涨停
  - 个股可能无明显吸筹期，受板块情绪带动
  - 龙头与跟风的分化：龙头连板，跟风只有首板
- **可利用性**: 中等。龙头股持续性好，但跟风股容易次日回落。
- **识别要点**: `sector_momentum_5d` 显著正值 + 同板块涨停数量 > 2

### 2.3 动机模型

所有涨停操作的底层逻辑一致：

```
吸引关注 → 上榜（龙虎榜/涨幅榜） → 引入跟风资金 → 手中持仓变现退出
```

这意味着：
1. **涨停是手段，不是目的** — 操盘方的真正目标是在高位出货
2. **涨停前必有蓄力** — 除非是纯游资闪电战，否则拉涨停之前必须建仓
3. **涨停后必有分歧** — 拉涨停本身会暴露意图，引发多空博弈
4. **持续性取决于筹码结构** — 吸筹充分 + 浮筹清洗到位 = 后续涨停持续性强

对策略的启示：
- 我们要找的是 **吸筹充分但尚未拉升** 的标的（生命周期的 "确认" 阶段）
- 而不是 **已经开始拉升** 的标的（追涨停 = 帮人抬轿）

## 3. 情绪维度分析

### 3.1 市场情绪周期

A股市场情绪存在明显的周期性波动，涨停策略的胜率与市场情绪阶段强相关：

| 情绪阶段 | 特征 | 对涨停策略的影响 |
|----------|------|------------------|
| **冰点** | 连板高度降低（max 2-3板），跌停数 > 涨停数，成交量萎缩 | 涨停持续性差，但超跌反弹型涨停的 T+20 收益反而较好 |
| **修复** | 首板数量回升，但连板成功率仍低 | 开始出现机会，但需精选 |
| **升温** | 连板高度提升（5板+），板块轮动加速 | 最佳窗口期，涨停持续性好 |
| **高潮** | 全市场普涨，涨停数量爆发（100+），情绪极度亢奋 | 胜率高但选择困难，需防范高潮退潮 |
| **退潮** | 龙头股断板，跟风股暴跌，情绪急剧转冷 | 高危期，避免操作 |

### 3.2 情绪信号的数据映射

当前系统中可以间接捕捉情绪信息的因子：

| 情绪维度 | 可用因子 | 解读 |
|----------|----------|------|
| 市场活跃度 | `sector_momentum_5d` | 板块普遍上涨 = 情绪偏暖 |
| 筹码松动度 | `turnover_change_20d` | 换手率上升 = 市场参与度提高 |
| 主力态度 | `main_strength_proxy`, `mf_net_percentile` | 机构资金流入 = 聪明钱看多 |
| 趋势确认 | `positive_day_ratio_20d` | 阳线占比高 = 上涨趋势确立 |
| 过热预警 | `climax_score`, `recent_vol_spike_max` | 量价极端 = 情绪过热 |

### 3.3 情绪驱动的行为偏差

理解市场参与者的情绪偏差，有助于设计更优的评分策略：

- **锚定效应**: 投资者倾向锚定前高，导致阻力位附近卖压增大。但对于龙头股，突破阻力位反而是强势信号（这是我们降低 `ceiling_penalty` 和 `resistance_penalty` 的理论依据）。
- **追涨杀跌**: 涨停后的次日高开低走（分歧），本质是短线客追涨后获利出逃。`post_spike_consolidation` 度量了这种行为消退的程度。
- **从众效应**: 板块轮动中的跟风效应，`sector_momentum_5d` 反映了这种板块级别的情绪共振。
- **损失厌恶**: 被套投资者在解套位附近倾向卖出，造成 60 日高位附近的抛压。但这对龙头股是伪信号——真正的龙头会突破解套盘。

## 7. 结构与形态识别路线图

### 7.1 从单因子到时序特征组合

当前评分完全基于**截面因子**（某日某只股票的单一指标值），但实际的涨停前兆是一组**时序特征**按先后顺序出现：

```
吸筹特征 (T-20 ~ T-10)
  → 量能蓄力特征 (T-10 ~ T-5)
    → 突破确认特征 (T-5 ~ T-1)
      → 涨停 (T)
```

这不是单个因子能捕捉的，而是**一组 K 线组合**构成的时序模式。

### 7.2 候选结构模式

| 模式 | 阶段 | 因子序列 | 说明 |
|------|------|----------|------|
| 机构吸筹型 | 吸筹→确认 | `accumulation`↑(T-20) → `vol_cv_10d`↓(T-10) → `vol_ramp_5v20`↑(T-5) | 先缩量吸筹，再温和放量 |
| 板块共振型 | 升温→共振 | `sector_momentum`↑(T-10) → `positive_day_ratio`↑(T-5) → `ma_alignment`↑(T-3) | 板块先行，个股跟随 |
| 超跌反弹型 | 退潮→修复 | `price_position_60d`↓(T-15) → `post_spike_consolidation`↓(T-10) → `up_volume_ratio`↑(T-3) | 超跌后资金抄底 |
